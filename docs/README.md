# Documentation Assets

This directory contains screenshots and GIFs for the README documentation.

## Required Assets

Create the following screenshots/recordings to document the application:

1. **demo.gif** - Full demo showing:
   - Typing a query
   - Tool calls appearing
   - Streaming response
   - Clicking a citation
   - PDF viewer transition

2. **chat-interface.png** - Chat interface showing:
   - User message
   - AI response with citations
   - Source cards below response
   - Tool call indicators

3. **pdf-viewer.png** - PDF viewer showing:
   - Split view layout
   - PDF document loaded
   - Navigation controls
   - Cited text highlighted

4. **generative-ui.png** - Generative UI showing:
   - Chart component
   - Table component (if implemented)
   - Card component

5. **dark-mode.png** - Dark mode showing:
   - Full interface in dark theme

## Recording Tips

- Use a screen recording tool like LICEcap, Gifox, or ScreenToGif
- Keep GIFs under 5MB for GitHub
- Use 1280x720 or similar resolution
- Frame rate of 10-15 fps for GIFs
